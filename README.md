# 闪彩 Atelier · 人物与关键词工坊 V3

本版新增人物库，收录用户这几批立绘按外貌分组的 28 份身份档案，明显重复的服装图归入同一档案。编号与描述名不等于已验证的官方角色姓名；用户可修改与校准。每个人物包含五官结构、头发分区、禁漂移项、正面/3/4/侧面推演及身体比例说明。

被用户否定“不够像”的生成三视图不进入网站、不作为母版。原图消息没有对应的可读原始文件路径，无法把原图像素直接内置到交付文件；人物卡明确显示“原图待关联”，可从本机选择原图（支持多张）存入 IndexedDB，不重绘、不发送外网。人物库 JSON 导出包含已关联的原图；普通工作空间 JSON 只含人物文字资料。

选择人物、视角、全身/半身及车站/教室/街角/海边方案后，导出文本会保留当次身份快照。侧面耳后、鼻部投影与完整身高不从裁切图伪装精确恢复；6.5—7 头身只是可校准的非 Q 版绘制目标。没有新图像生成或自动姿态识别 API，网站负责导出约束，实际同脸与比例仍需用原图核对结果。

默认新风格 STYLE-003 使用清晰细线、稳定固有色和简洁赛璐璐阴影；关闭默认暖黄配色与逆光卡，避免再次输出写实皮肤、纸纹和全局夕阳滤镜。旧卡与历史保留，便于追溯。当前验收使用 `node tests/characters.cjs`；以下 V2 说明仍适用于基础关键词编辑、导出及离线使用。

当前版本专注拆解、编辑、组合和导出关键词。人物和其他参考图由使用者在生图工具中自行提供。无需上传图片或启动服务器。

## 直接使用

下载 `dist/闪彩关键词工坊.html`，保存到电脑，用 Chrome、Edge 或 Safari 打开。该文件包含页面、样式、脚本和预置卡片，无需安装 Python、连接 Codex 或注册服务。手机内置文件预览可能不执行脚本，建议先用电脑浏览器查看。

1. 工作台切换维度、卡片，勾选词条。
2. 点“编辑卡片”，调整中文分析、英文词、观察依据、证据类型、适用范围、排除项和冲突 ID。
3. 默认保持“我会在生图时提供人物参考图”；人物名称和身份词是可选补充。
4. 导出完整英文 TXT、带来源的 JSON 或中文拆解 Markdown。
5. 在 ChatGPT Images 粘贴提示词，自行附上人物参考图，再核对脸型、眼睛、五官布局与发型。文字约束不能保证完全一致。

网页没有自动视觉分析、自动翻译或图像生成服务。新观察需要手动填写中英文。身份参考说明只表达输入策略，不代表网页已收到或识别人物图。

## 拆解内容

11 张预置卡、八个独立维度、42 个词条。原风格图的画法细分为轮廓线、线条密度、上色、阴影、高光、皮肤、头发、背景、纹理和边缘。构图、光照与配色是对用户第一张图的独立人工观察，未虚构精确角度、色温或统计。剧情、动作、场景和替换画法明确标为创作方案。人物身份卡默认留空，不杜撰无法读取的人物 ZIP 中的角色。

## 保存与备份

卡片、选择和导出历史保存在当前浏览器的 `shancai-keywords-v2` 存储中。换浏览器、移动文件或清理浏览数据可能影响保存；请定期导出完整工作空间 JSON。存储不可用时仍能临时编辑和导出，并会提示备份。

恢复前校验格式并要求确认；确认时先下载当前工作空间备份。导出历史保存当次词条和版本快照，不随之后编辑变化。图片输入始终为空 `generation_images: []`。

## 开发与打包

```sh
cd /workspace/-
python build_standalone.py
# 可选开发预览；日常使用无需此命令
python -m http.server 3000 --directory static
```

当前源码为 `static/index.html`、`static/keywords.js`、`static/style.css` 和 `static/keywords.css`。打包只用 Python 标准库，生成单个 HTML。`static/` 也可用于静态托管，尚未执行公网发布。

## 验证

```sh
python build_standalone.py
node --check static/keywords.js
node tests/keywords.cjs
```

需要 Playwright 与系统 Chromium。验收覆盖独立 HTML 加载、离线无外部请求、词条选择、持久化、编辑取消、拆分合并、版本溯源、三种格式导出、无图片编译、身份模式检查、未知与冲突检查、建卡、备份恢复、历史快照和手机布局。

云环境浏览器策略禁止直接导航 `file://`，此处以从内存返回完整 HTML 的独立测试域验证，无后台或外部请求。用户电脑直接打开的方式未在此受管浏览器中实测。
