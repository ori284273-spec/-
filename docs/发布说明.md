# 固定网址发布

此目录已包含完整的人物参考网站，无需 Python、Node 或数据库服务。

仓库管理员首次操作：打开仓库 Settings → Pages，在 Build and deployment 下将 Source 设为 Deploy from a branch，Branch 选择 main，目录选择 /docs，点击 Save。

GitHub 显示发布完成后，以其 Pages 设置页给出的地址为准。对于当前仓库，常规项目网址应为 `https://ori284273-spec.github.io/-/`，但在实际请求成功前不得称它已可访问。

若仓库是私有且账号套餐不支持 Pages，不要擅自公开仓库；需由所有者选择升级套餐或其他托管方案。

后续改动源码后运行 `python build_standalone.py`，会同步 docs/index.html；推送 main 后 GitHub Pages 会自动重新发布。用户继续打开固定网址即可，不必重新下载 HTML。

当前会话已验证本地页面，不具备编辑用户提供的 ChatGPT local 预览工具；该 local 链接和 GitHub Pages 是不同入口。
